# Decisions

Choices made while building the game where the rulebook, `readings.md` and `rulings.md` didn't settle the question. `rulings.md` wins over `readings.md`. All 20 rule interpretations in `readings.md` §1 were confirmed by the owner and are implemented as written; this file only lists the *extra* choices.

## Project / process
- **Inputs.** The rulebook, spreadsheet and `rulings.md` were copied into `source/`, so the repo is self-contained. `readings.md` is at the repo root.
- **Git.** The folder was already a git repository (one "Initial commit"), so I used it instead of running `git init` again.
- **Card data** is generated by `tools/build-cards.ps1` from the spreadsheet (names, colors, numbers, original text) plus each card's line in `readings.md`. The three rulings (Lion Finisher, Sun Cross, Forest Oak) replace their readings text. Output: `js/cards-data.js`.
- **Card names** are built as Family + Move (e.g. "Phoenix Chop") from each sheet's "Color Type Names" column. This fixes typos like "PhoenixChop" and fills the seven blank Black "Death" names, following readings.md.
- **Card ids**: `R`ed / Bl`U`e / `Y`ellow / `G`reen / blac`K` + number + family (e.g. `K3-death`). Characters are `C-` + first name (e.g. `C-asher`).
- **Decks.** There's no deck builder. Each player picks a character and "character's color" or "all colors"; the seed then picks 20 different cards × 2 copies = 40.
- **Previewing.** `tools/serve.ps1` is a small local server used only for automated checks. The game itself runs by double-clicking `index.html`.

## Engine architecture
- All state is one JSON object. `Solo.apply(state, action)` returns a new state or an error; the input state is never changed.
- **Choices** (pick a card, yes/no, a number) pause the action: `state.pending` holds the choice and the half-finished action. The next `{type:'choose'}` action re-runs the original action from its saved starting state with all the answers so far. This keeps every state plain JSON, so it's easy to send over a network later, and keeps replays exact.
- **Randomness** (the first player, shuffles, random discards) comes from a mulberry32 generator whose state is stored in `state.rng`. The same seed and the same actions always give the same game.
- A **mandatory choice with only one legal option** is made automatically, without asking.
- **Hidden-information choices** (e.g. the opponent choosing cards to discard for Phoenix Uppercut) are asked of that player. The UI shows the pass-the-device screen first.

## Turn / round flow
- **Setup:** the first player is picked at random from the seed. Both players draw 5. The first player decides on a mulligan, then the second.
- **Engage:** the player picks how many to draw (0, 1 or 2), then discards that many from their whole hand. If the deck runs short, they discard only as many as they actually drew.
- **Feint action:** only Blood Cross and Blood Uppercut have an action-menu Feint. Using one ends your turn, and it breaks an "engage, engage" chain.
- **Clash start / end effects:** the round's first player resolves first — character ability, then combo cards left to right — then the other player.
- **Clash win** triggers (Vlad, Phoenix Snap) resolve right after damage.
- **Reset** order: (0) energy refills to max (or stays higher if a bonus pushed it above max) and power resets to 0; (1) each player, first player first, discards any cards and draws up to 5; (2) end-of-clash effects; (3) combos go to their owners' discard piles, except kept cards (Phoenix Roundhouse, River Roundhouse, Ink Finisher), which stay in the combo in order as the leftmost cards; (4) if any deck is empty, the game ends.
- **Death check** happens after each effect finishes, so "you lose 2 and your opponent loses 2" (Flame Chop) is one simultaneous step. Both at 0 or less = draw.
- **Face-down cards discarded from a combo** stay face down in the discard pile. Every other discard is face up unless the card says otherwise.
- **Who controls a card** ("you" on the card) is the player whose combo it's in. A card planted in the opponent's combo works for them. "When discarded" effects belong to the card's owner, since the card goes to the owner's pile.
- **Returning a card "to your hand"** puts it in the named player's hand, and that player becomes its owner.
- **Order when a card is played:** (1) its combo enter (including Patience); (2) the player's character "when you play" ability; (3) other cards that watch for plays: Mantis Straight, Ink Roundhouse, Umbra Straight, then the opponent's Mantis Uppercut. "When you play" abilities also fire for cards played from the discard or deck, but not for cards that are only *put* into a combo.
- **Copying a combo-enter ability** (Cyber Chop, Forest Finisher): "this card" in the copied text means the copying card. Copy effects can't copy each other (prevents loops).
